## 1. Environment caveat affecting the audit

Near-duplicate detection (Jaccard ≥ 0.90 on character 5-shingles) is O(n²). It is
skipped (`-1`) for corpora above 3 000 items to stay inside the sandbox budget,
so all four corpora report `near_duplicates: -1`. Only **exact** duplicates were
measured here. MinHash/LSH near-duplicate sweep is a Phase-5 task.

## 3. Per-dataset findings

### 3.1 GWStance / GWSD

- **Schema verified** by reading the header of `GWSD.tsv`:
  `round, batch, sent_id, sentence, worker_0 … worker_7, disagree, agree, neutral, guid, in_held_out_test`.
- **Labels.** Eight worker votes per sentence (`agrees` / `disagrees` / `neutral`)
  plus Bayesian posteriors over the same three classes. Our loader takes the
  posterior argmax when present and falls back to the worker majority for the
  five screening sentences that carry no posterior (the repository README states
  those first five rows have no estimated distributions). The mapped label is
  therefore **derived, not gold**, and is marked as such in the loader docstring.
- **Class distribution:** NONE 986 (42.9 %), FAVOUR 864 (37.6 %), AGAINST 450
  (19.6 %). Imbalance ratio 2.191 — the NONE class is the majority, which is the
  opposite of what one might guess and makes NONE (not FAVOUR) the class that
  needs watching in macro-F1.
- **253 exact duplicate sentences** out of 2 300 (11 %). The corpus is built
  from sentences extracted out of 56 K news articles, so boilerplate recurs. Any
  split must be **grouped by sentence/`guid`** or these 253 will leak across
  train and test.
- **`in_held_out_test`** is the authors' own held-out flag; preserved so the
  English reference baseline can report an author-comparable number.
- **Licence: not granted.** There is **no `LICENSE` file** in the repository and
  no licence statement in its README (verified by grep). Treat as
  research-use-only; do not redistribute the file in this repo.

### 3.2 Dhoroni

- **What was actually obtained:** `ciol-research/Dhoroni`, `default/train`
  parquet, 2 290 rows, **exactly one column: `text`** (verified with pyarrow).
  Mean 2 581 characters, median 2 163, p95 5 923 — full news articles, not
  comments.
- **No stance column exists in the public artefact.** The paper advertises
  multi-perspective annotation (political influence, scientific/statistical
  data, authenticity, stance, stakeholder involvement), but none of it is in
  this file. Consequence: **Dhoroni cannot be stance supervision here.** It is
  usable for Bengali domain adaptation and climate-vocabulary EDA only.
- **Script check:** 2 289 / 2 290 Bengali, 1 Latin (flagged, not deleted, so the
  audit stays faithful).
- **Licence:** MIT per the dataset card. The article text remains third-party
  news content, so raw text is not redistributed.
- **Length implication:** ~2 581 characters ≈ 600–900 tokens; chunking to ≤ 128
  is mandatory for any CPU domain-adaptation pass.

### 3.3 IndicSentiment (hi, bn)

- **Obtained:** `validation` (156) + `test` (1 000) per language. The
  `train/{hi,bn}.json` path returns the literal string `Entry not found`, i.e.
  the training split is not published there — so only 1 156 rows per language.
- **Nature verified:** every record carries both `ENGLISH REVIEW` and
  `INDIC REVIEW`, i.e. the Indic side is a **machine translation of an English
  product/service review**, labelled `Positive`/`Negative`. Not social media,
  not stance.
- **Balance** 581 / 573 (ratio 1.014) — a clean sentiment probe, which is
  exactly how it will be used.
- **Sentiment ≠ stance worked counter-example:** "I hate how governments handle
  climate policies" is `Negative` sentiment yet is **not** `AGAINST` the claim
  that climate change is serious. A Positive→FAVOUR / Negative→AGAINST mapping
  is therefore forbidden, and is asserted against in `tests/test_dataset.py`.

## 4. Blocking conclusions

1. **No public resource in this set can supervise Hindi or Bengali climate
   stance.** Only the custom corpus can, and it does not exist yet. This is the
   project's critical path.
2. GWStance matches our claim *semantically* (its target sentence is the same
   claim) but is English; it serves as the English reference baseline and a
   comparative resource.
3. Dhoroni's public artefact is unlabelled Bengali news — a domain corpus, not a
   stance corpus.
4. IndicSentiment is translated reviews — an auxiliary probe only.
5. Leakage risk is real and quantified for GWSD (253 exact duplicates); all
   splits must be group-aware.
6. GWSD's majority class is NONE (42.9 %), so a trivial "always NONE" baseline
   would reach 42.9 % accuracy but only ~0.20 macro-F1. That is the floor the
   baselines must beat, and it is why macro-F1 and not accuracy is the primary
   metric.
